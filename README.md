# 🇯🇵 N3 語彙 — JLPT N3 Vocabulary Study App

> A clean, dark-mode web app to study, review, and test your JLPT N3 vocabulary.

🔗 **[Live Demo → suhas152.github.io/n3-goi](https://suhas152.github.io/n3-goi/)**

---

## ✨ Features

| Feature | Description |
|---|---|
| 📖 **Vocabulary Browser** | Browse all N3 words organized by chapter and part |
| 🔍 **Search** | Filter by kanji, hiragana, or English meaning |
| ⭐ **Bookmarks** | Save words for later — persisted in localStorage |
| 🃏 **Flashcards** | Flip cards per chapter/part, with shuffle support |
| 📝 **Test Mode** | 30-question multiple choice quiz from all chapters |

---

## 📚 Chapters Covered

- **Chapter 1** — 人と人との関係 (Relationships between People)
- **Chapter 2** — 毎日の暮らし① (Daily Life 1)
- **Chapter 3** — 毎日の暮らし② (Daily Life 2)
- **Chapter 4** — 私たちの町 (Our Town)

---

## 🚀 Run Locally

No build step needed — pure HTML, CSS, and vanilla JS (ES modules).

```bash
npx serve .
```

Then open [http://localhost:3000](http://localhost:3000)

---

## 🛠 Tech Stack

- Vanilla JavaScript (ES Modules)
- CSS custom properties — dark theme
- localStorage for bookmark persistence
- No frameworks, no dependencies
